# 黑音 · Sonic

Android 音效试验应用，当前版本 **1.0**。

## 下载

- [下载 Android 安装包](Sonic-1.0.apk)
- [下载完整源码包](Sonic-source.zip)

源码以压缩包保存，解压后 `sonic/` 目录包含 Java 工程、构建脚本、原生库、测试和对应上游源码快照。

## 功能

- 8D 左右声像移动，可调往返速度与深度。
- 四种耳机空间风格，支持独立空间强度。
- 小房间、小音乐厅、大音乐厅三种独立混响，可调比例。
- 多种音效预设和 HiFi 听感微调。
- 音效、空间、连接三个标签页。
- 汽水音乐完整处理通道及连接诊断。

## 使用

覆盖安装当前修复版 0.8.1 / 0.9.0，可保留设置。初代旧包需单独安装。仅打包 ARM64 原生库。

完整通道：先启动 Shizuku 并授权黑音，启动完整音效，允许系统内部音频捕获，然后播放汽水音乐。免 Shizuku 测试模式仅支持监测和 5 秒低音量叠加试听，不替换原声。

空间音频是固定声场模拟，不包含头部追踪或 Dolby Atmos 解码。基础完整通道已由用户在小米 14 / Android 16 上运行；不同系统、耳机及输出路径的兼容性仍需实际验证。
